# RAG Chatbot: Ask Questions About Your CSV Data with a Local LLM

A **Retrieval-Augmented Generation (RAG)** chatbot that answers natural-language questions about a CSV dataset. It runs **fully locally**: embeddings come from Sentence-Transformers, vectors are stored in **ChromaDB**, and answers are generated by a model served by **LM Studio**. No API key or cloud service is needed.

It ships with the **video game sales** dataset (`data/vgsales.csv`, about 16,000 titles). You can ask things like *"What are the best-selling games?"* or *"Which publisher sold the most in Europe?"*. Answers are in **French**.

---

## How it works

```
 CSV ──► pandas ──► analytical summaries ──► text chunks ──► MiniLM embeddings ──► ChromaDB
                     (top games, platforms,                                          │
                      regions, publishers, genres)                                   │
                                                                                     ▼
 Question ──► embed ──► retrieve top-k (k=10) chunks ──► prompt + context ──► LM Studio LLM ──► Answer
```

1. **Load:** the CSV is read with pandas.
2. **Summarise:** instead of embedding raw rows, the bot builds analytical documents: an overall summary, the top 20 games by global sales, the best titles per platform, sales by region (NA/EU/JP/Other), and the top publishers and genres.
3. **Chunk and embed:** documents are split (1,500 characters, 200 overlap) and embedded with `sentence-transformers/all-MiniLM-L6-v2`.
4. **Store:** vectors are persisted in a local ChromaDB (`./chroma_db`).
5. **Retrieve and generate:** the 10 most relevant chunks are put into the prompt and sent to the LM Studio OpenAI-compatible endpoint (`/v1/chat/completions`).

## Features

- 💬 **Web interface** (Flask) with a chat UI at <http://localhost:5000>
- 🖥️ **CLI mode** with example questions and an `info` command
- 🔒 **Local and private:** the data never leaves your machine
- 📊 Works with any CSV; the default prompt and summaries are tuned for the video game sales dataset

## Tech stack

| Component | Technology |
|---|---|
| Orchestration | LangChain 0.1 (`langchain`, `langchain-community`) |
| Embeddings | Sentence-Transformers `all-MiniLM-L6-v2` (Hugging Face) |
| Vector store | ChromaDB 0.4 |
| LLM | Any model loaded in **LM Studio** (OpenAI-compatible server) |
| Data | pandas |
| Web | Flask |

## Getting started

### 1. Prerequisites
- Python 3.10+
- [LM Studio](https://lmstudio.ai) with a chat model downloaded (for example Mistral 7B Instruct, Llama 3 8B Instruct, or Qwen 2.5 7B)

### 2. Install

```bash
git clone https://github.com/fidaaltf58/RAGCHATBOT.git
cd RAGCHATBOT
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS / Linux

pip install -r requirements.txt
```

### 3. Start LM Studio
1. Open LM Studio and load a model.
2. Go to **Developer → Start Server**. It listens on `http://localhost:1234`.
3. Check the connection:

```bash
python test_lmstudio.py
```

### 4. Run the chatbot

**Web interface**

```bash
python app.py
```

Then open <http://localhost:5000>.

**Command line**

```bash
python main.py
# Press Enter to use data/vgsales.csv, or type the path to another CSV
```

The first run downloads the embedding model and builds the vector store, which can take a minute.

## Configuration

| Setting | Where | Default |
|---|---|---|
| LM Studio URL | `rag_chatbot.py`, `config/config.py` | `http://localhost:1234/v1` |
| Embedding model | `rag_chatbot.py`, `config/config.py` | `sentence-transformers/all-MiniLM-L6-v2` |
| Chunk size / overlap | `rag_chatbot.py` | 1500 / 200 |
| Retrieved chunks (k) | `rag_chatbot.py` | 10 |
| Vector store directory | `config/config.py` | `./chroma_db` |
| System prompt | `RAGChatbot.SYSTEM_PROMPT` | French data-analyst assistant |

## Project structure

```

├── main.py                 # Interactive CLI

├── test_lmstudio.py        # LM Studio connection test

└── documents/test.txt      # Sample text document
```
